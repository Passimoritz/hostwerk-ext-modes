# Modi – Hostwerk-Erweiterung

Dienste für eine Aufgabe mit einem Klick: „Arbeit“ mit Webserver und Datenbank, „Minecraft-Abend“ nur mit dem Server.
Wechseln startet genau diese Dienste und stoppt die anderen – solange ein Modus aktiv ist, folgt ihm Hostwerks Autostart.
Auf Wunsch bringt ein Modus eine eigene Akzentfarbe und eine eigene Seitenleiste mit.

**Wo:** Aufgaben → Modi, der Umschalter auf der Übersicht und unten in der Seitenleiste.

**Daten:** bleiben in Hostwerks Einstellungen (`profiles`) – Entfernen beendet den aktiven Modus, die Modi bleiben für eine
erneute Installation erhalten.
